# 吉吉的家 · C1 原图重建

公开网址：https://feimi66.github.io/jijis-home/

2026-10-09 用户提供新原始房屋平面图，确认右侧 C1 为自家。本版替换旧示意户型，重建北侧厨房/生活阳台、两间次卧、客餐厅、两卫、过道与主卧入口、南伸主卧及与主卧连通的南阳台。旧版保留在 Git 历史 a278e086。

- C1 整套装修，其他 C2/C3、公区楼梯、电梯、外廊与原玄关入口为独立可关闭毛坯轮廓；客厅南侧标注区域留为空地。
- 点击“周边毛坯”开关或右侧显示选项切换；“整层轮廓”显示楼层关系；“我家整套”和“完整平面”聚焦 C1。
- 手机下方“范围”同时提供周边显示开关、整层视图和过道方案。
- 拖动旋转、滚轮在鼠标指向位置缩放；方向键按照当前视角移动镜头，本次按用户要求将上下和左右方向反转，平移速度可独立调节0.25–3.00倍（默认保留1.50倍）；指南针随镜头旋转、点击回正。
- 所有门和三只电视柜抽屉可开关；视角滑动、方向键平移及漫游速度可分别调整并记住。

app.js 与 index.html 内嵌脚本保持一致。仅静态文件，GitHub Pages 可直接部署。

照片没有北向标记，N 以图面上方暂定。门窗宽度、手绘遮挡门区、南阳台进深和背景毛坯为近似设计，具体边界与估读情况见 LAYOUT-NOTES.md；本模型用于布局预览。

厨房和餐厅之间完全开放；主卧与南阳台之间无墙、门框或推拉门，地面连续。原玄关已移出自家选择及轮廓，入口公区随周边毛坯显示。

过道与主卧方案取代原阳台布置切换，主卧与南阳台保持一体，固定休闲凳和低柜。默认B封闭入口，选择会保存在本机：

- A独立过道：90cm主卧门设在北侧；主卫80cm门直连主卧，原北门封墙；客卫80cm门移到西侧过道中部，南侧原门封墙，淋浴移至东北角避开开门范围。
- B封闭入口：过道南侧墙与客卫南墙齐平；86cm主卧门正对客房门，主卫入口向北延伸0.9m，80cm门正对电竞房门。主卫由公共过道进入，客卫仍由主卧进入。

切换同步更新墙面并集、直角接点、踢脚线、门框、标签、菜单和漫游碰撞。每方案7扇可开关门，主卧入口默认关闭；视角与速度设置独立保存。
