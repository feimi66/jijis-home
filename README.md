# 吉吉的家 · C1 原图重建

公开网址：https://feimi66.github.io/jijis-home/

2026-10-09 用户提供新原始房屋平面图，确认右侧 C1 为自家。本版替换旧示意户型，重建北侧厨房/生活阳台、两间次卧、客餐厅、两卫、套间入口、南伸主卧和窄南阳台。旧版保留在 Git 历史 a278e086。

- C1 整套装修，其他 C2/C3、公区楼梯、电梯和屋面为独立可关闭毛坯轮廓。
- 点击“周边毛坯”开关或右侧显示选项切换；“整层轮廓”显示楼层关系；“我家整套”和“完整平面”聚焦 C1。
- 手机下方“范围”同时提供周边显示开关、整层视图和阳台布置。
- 拖动旋转、滚轮在鼠标指向位置缩放；方向键按照当前视角平移；指南针随镜头旋转、点击回正。
- 所有门和三只电视柜抽屉可开关；视角滑动速度及漫游速度可调整并记住。

app.js 与 index.html 内嵌脚本保持一致。仅静态文件，GitHub Pages 可直接部署。

照片没有北向标记，N 以图面上方暂定。门窗宽度、手绘遮挡门区、南阳台进深和背景毛坯为近似设计，具体边界与估读情况见 LAYOUT-NOTES.md；本模型用于布局预览。
