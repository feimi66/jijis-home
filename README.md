# 吉吉的家 · 3D看房

这是根据用户提供的约130㎡户型图制作的可分享3D看房网页。

2026-10-07更新：重建客厅到过道的连续通道、图示门位与可开关门扇，增加手机开关门面板、平面核对与漫游墙体阻挡。尺寸图的标注冲突及未标注尺寸见 [户型修正记录](./LAYOUT-NOTES.md)。

## 已完成

- 现代原木风：暖白墙面、浅橡木、少量黑色线条
- 2.7米层高
- 客餐厅：约3米L形沙发、75寸电视、六人餐桌
- 封闭式厨房和玻璃推拉门设计方向
- 卧室A：双人电竞房，两套电脑，每人一台显示器
- 卧室B：客房兼未来儿童房
- 卧室C：1.8米床主卧，保留衣帽间
- 阳台A：洗衣机位，并预留未来烘干机条件
- 阳台B双方案切换：并入主卧 / 独立电脑与茶室
- 鸟瞰旋转、缩放、平面核对、房间快捷视角
- 9处门位支持点击开关，关闭门会阻挡漫游；衣帽间保持开放入口
- 第一人称漫游，支持键盘和手机方向键
- 墙体、家具、房间标签显示开关
- 浏览器原生分享或复制链接
- 电脑、平板和手机自适应界面

## 本地查看

现在可以直接双击 `index.html` 打开。首次打开需要联网加载 Three.js 3D运行库，建议使用最新版 Chrome 或 Edge。

如果浏览器对本地文件有额外限制，也可以通过本地网页服务打开。如果电脑安装了 Python，可在此目录运行：

```powershell
python -m http.server 8080
```

然后打开：`http://localhost:8080`

## 发布并获得分享链接

这个项目是纯静态网页，可直接发布到 Vercel、Cloudflare Pages 或 GitHub Pages。

最省事的方法：

1. 登录 Vercel。
2. 新建项目并上传整个 `jijis-home` 文件夹。
3. 不需要填写构建命令，直接部署。
4. 部署完成后会获得公开网址，页面右上角“分享”按钮即可转发。

## 换成精细GLB模型

当前版本根据平面图使用 Three.js 生成可运行的轻量模型。以后有 Blender、SketchUp 或其他软件导出的精细模型时：

1. 将模型命名为 `house.glb`，放入 `assets` 文件夹。
2. 使用以下网址打开：`https://你的域名/?model=assets/house.glb`

网页会保留现有房间导航、方案切换和分享界面，同时加载精细GLB模型。正式替换时，建议进一步校准模型原点、比例和房间视角。

## 设计精度说明

第一版用于空间方案比较和在线浏览，不可替代施工图。局部墙厚、门窗尺寸、梁柱和水电位置仍应以现场复尺为准。

## 窗户与门框更新

- 普通房间使用嵌在墙内的窗户，窗台下方和窗顶上方均补齐墙体。
- 只有客厅保留落地全景玻璃；卫生间使用高位磨砂窗。
- 阳台B使用三扇普通墙窗；独立方案采用普通墙体与可操作的玻璃推拉门。
- 门框、门顶墙与相邻墙体连续相接，门槛与地面齐平。

## 浏览与家具更新

- 客厅改成一整块无框全景玻璃，普通房间保持墙窗。
- 75寸电视使用清晰画面、机身及电源灯；电视柜有三个可操作收纳抽屉。
- 同材质墙体与地坪合并外表面，家具采用细小圆角。
- 电脑滚轮缩放跟随鼠标位置，支持靠近查看家具。
- 漫游速度范围0.25–2.00米/秒，默认0.65米/秒，自动记住设置。
- “电视与收纳”可直接查看电视和电视柜；手机“开关门”面板也可开关抽屉。
